# Research Thread Template

Use this template for a living public synthesis. Working judgments are author interpretations, not field consensus. Confidence refers only to the stated scope, factual claims require public sources, and public-level tests must not expose unpublished protocols or submission-sensitive novelty.

| Field | Value |
|---|---|
| Status | Scoping / Active / Stable / Dormant / Archived |
| Last reviewed | YYYY-MM-DD |
| Evidence cutoff | YYYY-MM-DD |
| Confidence | Not assessed / Low / Medium / High |
| Scope | Define the systems, tasks, settings, and exclusions covered by this thread. |
| Discussion | Add the canonical GitHub Discussion when the thread is ready for discussion. |

## Why this matters

Explain why resolving the question would matter for robotics behavior, evaluation, or understanding. Avoid unsupported impact claims.

## Key question

State one precise question that the thread will maintain.

## Scope and definitions

Define important terms, covered settings, and explicit exclusions.

## Current working judgment

State the current scoped interpretation and reference supporting or challenging Evidence IDs. Use `Not yet assessed` while the thread is in Scoping.

## Confidence rationale

Explain why the confidence level is appropriate within the stated scope. Name missing or conflicting evidence.

## Evidence ledger

Use stable IDs so judgments, contradictions, and hypotheses can link back to evidence.

| ID | Public source | Role | What it establishes | Limitations |
|---|---|---|---|---|
| E1 | Public paper, dataset, benchmark, or official artifact | Supports / Challenges / Context | Evidence-backed statement | Scope and uncertainty |

## Assumptions in current methods

List assumptions found in public sources and reference the relevant Evidence IDs.

## Contradictions

Record tensions between public findings, assumptions, or evaluation practices. State why the tension remains unresolved.

## Open questions

List questions that follow from the evidence and contradictions rather than from unsupported speculation.

## Falsifiable hypotheses

| Hypothesis | Prediction | Disconfirming evidence | Public-level test |
|---|---|---|---|
| Scoped statement | Observable outcome | Result that would reject or revise it | Public-safe evaluation outline |

Public-level tests should describe the evidence needed without exposing unpublished protocols, private setups, internal benchmarks, or submission-sensitive details.

## What would change this judgment

Name the public evidence, counterexample, or evaluation result that would materially revise the current judgment or confidence.

## Representative sources

List only verified public sources. Prefer primary, official, or peer-reviewed material and keep bibliographic details accurate.

## Related research threads

Link only to existing Research Threads and explain the relationship briefly.
